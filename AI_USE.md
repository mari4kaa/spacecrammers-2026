# How AI was used in FireSight

NASA Space Apps Challenge 2026, team Spacecrammers. This file is the project's AI-use disclosure, as required by the Space Apps rules for SI (AI) tools. The same statement appears on the dashboard (header, footer and **Method → How AI was used**), in the page's `<meta name="ai-disclosure">` tag, in the header of every script and in the data READMEs.

**What the team did:** chose the challenge approach and the dashboard features, supplied papers, reviewed the results, asked for corrections, and deployed and published the site.

**AI tools used:**
- **Claude (Anthropic)**, used through claude.ai while building the project.
- **Google Gemini** (`gemini-3.5-flash-lite`, fallback `gemini-3.1-flash-lite`) generates the live answers in **Ask the data** on the public site.

| Part | What AI did | How it is checked |
|---|---|---|
| Code: `web/template.html`, `docs/index.html`, `scripts/*.py`, `worker/` | Written with Claude | Run, tested in a browser and published by the team; all code is in this repository |
| Test matrix and data-quality log: `data/tests.csv`, `data/quality_log.csv` | Cleaning rules (units, typos, ranges, duplicates) written with Claude and run by `scripts/normalize.py` over the PSI tables | Every value keeps its PSI file and row; every change is logged with a code and shown on the Data quality tab |
| Flammability-boundary points: `data/boundary/` | Digitized from BASS-II report Figure 6.10 with Claude-written code and checked by Claude against zoomed crops of the figure; Tables 7.1 and 2.1 copied by Claude | Method in `data/boundary/README.md`; the refit is compared with the report's own equation |
| Safety-evidence tables: `data/evidence/` | Extracted by Claude from published papers and a PSI report table | Rows compared with the source pages; every row names its source |
| Investigation summaries, findings, relevance notes, page text: `data/curated.json` | Written by Claude from the sources named in each finding | All findings checked by Claude against the source passages on 2026-11-14 |
| Report search passages: `docs/passages.json` | Text extracted from public-use PDFs by a Claude-written script | Each passage keeps its document and page |
| Design takeaways (Safety evidence tab, Explore summary, `design_takeaways` assistant tool) | Rules and wording written with Claude | Every number is computed from the data for the chosen scenario; each card names its source and the conditions that were tested |
| Ranking scores, boundary fit, gap counts | No AI at run time: deterministic code | Formulas on the Method tab and in the code |
| Live answers (Ask the data) | Generated by Google Gemini when a user asks, using only lookup tools over this dataset | Every answer is labelled as AI-generated; the page checks each citation against what the lookups returned and corrects or removes wrong ones |

**Images, video, audio:** the dashboard has no AI-generated images, video or audio. Charts are drawn by Plotly from the data. Any AI-generated image or video in the demo will carry a visible watermark.

**NASA branding:** FireSight uses no NASA logos, flags or mission insignia, and it is not an official NASA product. NASA PSI data are used under CC0 and cited by DOI.
