# How AI was used in InfoFlame

NASA Space Apps Challenge 2026, team Spacecrammers. This file is the project's AI-use disclosure, as required by the Space Apps rules for SI (AI) tools. A short version appears on the dashboard (header, footer and **Method → AI use**); the full statement is also in the page's `<meta name="ai-disclosure">` tag, in the header of every script and in the data READMEs.

**What the team did:** chose the challenge approach and the dashboard features, supplied papers, reviewed the results, asked for corrections, and deployed and published the site.

**AI tools used:**
- **Claude (Anthropic)**, used as an assistant through claude.ai while building the project and editing the demo video.
- **Google Gemini** (`gemini-3.5-flash-lite`, fallback `gemini-3.1-flash-lite`) generates the live answers in **Ask the data** on the public site.
- **ElevenLabs** (text-to-speech, voice "Max - Elearning and Documentary") generated the voice-over of the 30-second demo video.

| Part | AI's role | How it is checked |
|---|---|---|
| Code: `web/template.html`, `docs/index.html`, `scripts/*.py`, `worker/` | Written with Claude's assistance | Run, tested in a browser and published by the team; all code is in this repository |
| Test matrix and data-quality log: `data/tests.csv`, `data/quality_log.csv` | Cleaning rules (units, typos, ranges, duplicates) written with Claude's assistance and run by `scripts/normalize.py` over the PSI tables | Every value keeps its PSI file and row; every change is logged with a code and shown in the data-quality report on the Data & export page |
| Flammability-boundary points: `data/boundary/` | Digitized from BASS-II report Figure 6.10 with code written with Claude's assistance, and checked against zoomed crops of the figure with Claude's assistance; Tables 7.1 and 2.1 transcribed with Claude's assistance | Method in `data/boundary/README.md`; the refit is compared with the report's own equation |
| Safety-evidence tables: `data/evidence/` | Extracted with Claude's assistance from published papers and a PSI report table | Rows compared with the source pages; every row names its source |
| Investigation summaries, findings, relevance notes, page text: `data/curated.json` | Written with Claude's assistance from the sources named in each finding | All findings checked against the source passages with Claude's assistance on 2026-11-14 |
| Report search passages: `docs/passages.json` | Text extracted from public-use PDFs by a script written with Claude's assistance | Each passage keeps its document and page |
| Design takeaways (Safety evidence tab, Explore summary, `design_takeaways` assistant tool) | Rules and wording written with Claude's assistance | Every number is computed from the data for the chosen scenario; each card names its source and the conditions that were tested |
| Ranking scores, boundary fit, gap counts | No AI at run time: deterministic code | Formulas on the Method tab and in the code |
| Demo video voice-over | Generated by ElevenLabs from the narration script, which was drafted with Claude's assistance and edited by the team | The video states "Voice-over: AI text-to-speech (ElevenLabs)" on screen; the narration only describes features shown in the screen recording |
| Demo video editing | Cuts, timing, subtitles, labels and end card made with Claude's assistance (using ffmpeg) from the team's screen recordings and voice-over; the team chose what to show and reviewed each version | The video states "Video edited with Claude (Anthropic)" on screen |
| Live answers (Ask the data) | Generated by Google Gemini when a user asks, using only lookup tools over this dataset | Every answer is labelled as AI-generated; the page checks each citation against what the lookups returned and corrects or removes wrong ones |

**Images, video, audio:** the dashboard has no AI-generated images, video or audio. The demo video is made from the team's screen recordings of the dashboard. Its voice-over is AI-generated (ElevenLabs text-to-speech) and the video was edited with Claude's assistance (cuts, timing, subtitles, labels); both are stated on screen. The five photos (Gaps and Compare tabs, files in `docs/img/`) are NASA images, credited and linked under each one and listed in `SOURCES.md`; they were only resized and, for the Saffire photo, cropped. Charts are drawn by Plotly from the data.

**NASA branding:** InfoFlame uses no NASA logos, flags or mission insignia, and it is not an official NASA product. NASA PSI data are used under CC0 and cited by DOI.
